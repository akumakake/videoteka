# AnimeLibrary — Видеотека аниме

Веб-приложение для просмотра каталога аниме с системой авторизации, отзывами и админ-панелью.

## Возможности

- 📺 **Каталог аниме** с фильтрацией по жанру, рейтингу и поиску
- 🔐 **Регистрация и авторизация** с JWT токенами
- 👑 **Админ-панель** для управления контентом (только для администратора)
- 💬 **Отзывы** с модерацией (одобрено/на проверке/отклонено)
- 📅 **Сезоны и эпизоды** с детальной информацией
- 📊 **Статистика** по тайтлам и пользователям
- 📱 **Адаптивный дизайн** для всех устройств

## Технологии

### Бэкенд
- **Node.js** — серверная платформа
- **Express.js** — веб-фреймворк
- **SQLite3** — база данных
- **JWT** — авторизация
- **bcryptjs** — хеширование паролей

### Фронтенд
- **Чистый HTML/CSS/JavaScript** — без фреймворков
- **Адаптивная верстка** — для мобильных устройств
